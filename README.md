# Shallon Connect Desktop update feeds

This public repository serves the HTTPS update-feed paths for Shallon Connect Desktop.

## Status

The feeds are scaffolding only and are **inactive**. No installer, signature, release asset, real version, or update manifest has been published. The `0.0.0` placeholders contain no platform packages and cannot deliver an update.

- Preview feed: [`feeds/preview/latest.json`](feeds/preview/latest.json)
- Production feed: [`feeds/production/latest.json`](feeds/production/latest.json)

Installers, signatures, checksums, and release notes will only be distributed as GitHub Release assets after a separately authorized Preview test. This repository must never contain private source code, school/student data, credentials, local configuration, logs, database exports, backups, or private signing keys.

GitHub Pages publishes this repository over HTTPS. Treat every file and URL here as public.
